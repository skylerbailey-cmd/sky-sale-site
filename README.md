# sky-sale.com

The marketing site for SkySale. Plain HTML, no build step and no
dependencies — open `index.html` in a browser to work on it.

GitHub Pages serves this repository's root on every push to `main`.
`CNAME` holds the custom domain; deleting that file would move the site
back to the github.io address.

## Screenshots

`assets/` holds captures of the real SkySale interface, photographed against
a seeded demonstration store — "Marigold Skin Studio", whose staff,
customers, sales and bookings are all invented.

Never replace them with captures of live data. Every name, email address and
figure visible on this site must be fictional; the shops' real customers must
not appear in marketing material. Regenerate the demo store rather than
editing the images by hand.
